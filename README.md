☕ Programación Orientada a Objetos en Java

Este repositorio contiene los programas, prácticas y proyectos desarrollados durante la materia Programación Orientada a Objetos (POO), utilizando el lenguaje Java.
El propósito de esta carpeta es almacenar y documentar todo el trabajo realizado a lo largo del curso, aplicando los fundamentos y principios de la POO.

📂 Contenido

Clases y objetos: ejemplos de creación, instanciación y uso de métodos.

Encapsulamiento: manejo de modificadores de acceso, getters y setters.

Herencia: reutilización y extensión de clases base.

Polimorfismo: implementación de comportamientos dinámicos mediante sobreescritura de métodos.

Abstracción e interfaces: definición de clases abstractas e interfaces para estructurar el código.

Manejo de excepciones: control de errores y uso de bloques try-catch-finally.

Colecciones y genéricos: uso de estructuras de datos como ArrayList, HashMap, etc.

Proyecto final: aplicación completa que integra los conceptos aprendidos durante el curso.

🛠️ Tecnologías y herramientas

Lenguaje: Java (versión 8 o superior)

Entorno de desarrollo: IntelliJ IDEA / NetBeans / VS Code

Control de versiones: Git y GitHub

🎯 Objetivo

Aplicar los principios fundamentales de la Programación Orientada a Objetos —abstracción, encapsulamiento, herencia y polimorfismo— para desarrollar software modular, reutilizable y mantenible en Java.
